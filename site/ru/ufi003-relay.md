# USB-модем UFI003 в роли ретранслятора

UFI003 — 4G USB-модем на msm8916. С прошитой системой OpenStick Debian 11 на нём работает Linux-ретранслятор OpenXPlay: ретранслятор запускается сам при подаче питания на модем, а головное устройство показывает CarPlay в собственном браузере. Нужные файлы поддержки находятся в [OpenXPlay-Hardware](https://github.com/OpenXPlay/OpenXPlay-Hardware/tree/main/UFI003).

Wi-Fi в UFI003 не поддерживает диапазон 5 ГГц, поэтому его точка доступа работает на 2,4 ГГц.

## Два способа установки {#install}

Установку выполняет [OpenXPlay Flasher](https://github.com/OpenXPlay/OpenXPlay-Flasher) на вашем компьютере. Он записывает на модем три слоя: базовую систему (OpenStick Debian 11), поддержку устройства и ретранслятор OpenXPlay. Когда выходит новая версия ретранслятора, обычно достаточно обновить только слой ретранслятора, без повторной прошивки.

| | Поручить установку ИИ-ассистенту (рекомендуется) | Установить самостоятельно с помощью Flasher |
| --- | --- | --- |
| Что делаете вы | Отправляете одно сообщение ИИ-ассистенту на компьютере и подтверждаете ключевые действия | Открываете приложение Flasher и выполняете его шаги |
| Загрузка и проверка файлов | ИИ скачивает их по подписанному списку пакетов и проверяет | Вы скачиваете их по ссылкам, которые показывает Flasher; Flasher их проверяет |
| Подходит вам, если | Вы уже пользуетесь ИИ-ассистентом, который умеет выполнять команды, например Claude Code или Codex | Вы хотите видеть каждый шаг сами или не пользуетесь таким ассистентом |

Оба способа используют один и тот же Flasher и один и тот же подписанный список пакетов, с одинаковым резервным копированием разделов модема и одинаковыми проверками безопасности. В Windows встроенная поддержка adb и fastboot появилась в версии 0.2.0-beta.2; требования к драйверам и результаты проверки на оборудовании см. ниже.

## Поручить установку ИИ-ассистенту (рекомендуется) {#ai}

Мы написали [инструкции по установке для ИИ-ассистентов](https://openxplay.org/agents/ufi003-install.md). Ассистент, прочитавший их, скачивает на ваш компьютер Flasher и нужные файлы, проверяет их SHA-256 и устанавливает всё через командную строку Flasher; если что-то идёт не так, он может разобраться с реальной ситуацией на вашем компьютере. Нужен ИИ-ассистент, способный выполнять команды на вашем компьютере, например [Claude Code](https://claude.com/claude-code) или [OpenAI Codex](https://github.com/openai/codex).

1. Подключите UFI003 к компьютеру по USB напрямую, а не через концентратор без питания. По возможности отключите другие телефоны.
2. Откройте ИИ-ассистента и отправьте ему это сообщение:

   ```text
   Read https://openxplay.org/agents/ufi003-install.md
   and follow it exactly to turn the UFI003 USB dongle plugged into
   this computer into an OpenXPlay relay with OpenXPlay Flasher.
   Tell me what each step will do before you run it, and wait for me
   to type the dongle's serial number before anything erases it.
   ```

3. Отвечайте на вопросы ассистента. Следующее остаётся за вами:
   - проверить по серийному номеру, что найденное ассистентом устройство — ваш UFI003;
   - самостоятельно ввести серийный номер модема, прежде чем что-либо его сотрёт;
   - не отключать модем и не давать компьютеру выключиться или уснуть во время установки;
   - добавить собственный идентификатор CarPlay, как описано в разделе [Добавьте идентификатор CarPlay](#step-identity).

Когда установка завершится, ассистент расскажет, как открыть страницу администрирования ретранслятора. Затем продолжайте с раздела [Выберите сеть](#step-network).

::: warning Следите за командами, которые выполняет ассистент
ИИ-ассистент выполняет команды на вашем компьютере. Используйте ассистента, которому доверяете, и просматривайте каждую команду, которую он хочет выполнить; просите объяснить всё, что вам непонятно. Инструкции велят ему работать только с этим UFI003, не трогать другие устройства компьютера, никогда не читать ваши файлы идентификатора, никогда не отключать проверку подписи и никогда не перезаписывать разделы через fastboot по собственной инициативе.
:::

## Установить самостоятельно с помощью Flasher {#flasher}

Flasher — настольное приложение для Windows и macOS. Подключите UFI003 к компьютеру по USB, и он распознает модем, покажет версию каждого слоя и проведёт вас через установку.

::: info В Windows
Версии 0.2.0-beta.2 и новее поддерживают adb и fastboot напрямую через WinUSB. Внешний сервер adb не нужен; уже запущенный сервер adb по-прежнему можно использовать.

Для вывода списка устройств драйвер adb не нужен, но для обмена данными соответствующий интерфейс должен использовать драйвер **WinUSB**. Если устройство отображается в списке, но обмен данными с ним невозможен, проверьте его **интерфейс ADB** в диспетчере устройств или его **интерфейс fastboot** после входа в загрузчик; для каждого режима драйвер может понадобиться установить отдельно. Меняйте только этот интерфейс. Не трогайте **сетевой адаптер RNDIS** и его сетевой драйвер и не заменяйте драйвер для всего составного USB-устройства.

Для устройства fastboot UFI003 с ИД оборудования `USB\VID_18D1&PID_D00D` [подписанный драйвер Android Bootloader Interface из каталога Центра обновления Майкрософт](https://www.catalog.update.microsoft.com/ScopedViewInline.aspx?updateid=76f2c233-6100-4a64-8bee-113c2da0991d) проверен в Windows 11. Устанавливайте его только для устройства fastboot с точно таким ИД; не трогайте драйверы адаптера RNDIS и всего составного устройства.
:::

### Запросы драйверов в Windows и их установка {#flasher-windows-drivers}

**Предлагает ли приложение установить драйверы?** В 0.2.0-beta.2 ошибки при чтении устройства или открытии fastboot отображаются в области ошибок приложения. При отсутствии зарегистрированного интерфейса WinUSB может появиться `needs a WinUSB driver`, `install the ADB/fastboot WinUSB driver` или `has no WinUSB … interface`. Эти технические подробности могут оставаться на английском языке. Приложение не скачивает и не устанавливает драйверы, и установщика драйверов в один клик в нём нет.

1. Найдите интерфейс ADB или fastboot этого UFI003 в диспетчере устройств. Откройте «Свойства» → «Сведения» → «ИД оборудования» и проверьте ИД для текущего режима. Не выбирайте адаптер RNDIS или всё составное USB-устройство.
2. Скачайте и распакуйте подписанный драйвер, соответствующий этому ИД оборудования, версии и архитектуре Windows. Указанный выше драйвер из каталога Центра обновления Майкрософт подходит для проверенного интерфейса fastboot `USB\VID_18D1&PID_D00D`; для других ИД нужен свой соответствующий драйвер.
3. Щёлкните этот интерфейс правой кнопкой мыши, выберите «Обновить драйвер» → «Найти драйверы на этом компьютере» и укажите распакованную папку. См. [инструкции Майкрософт по ручной установке](https://support.microsoft.com/en-us/windows/update-drivers-through-device-manager-in-windows-ec62f46c-ff14-c91d-eead-d7126dc1f7b6). Не отключайте обязательную проверку подписи драйверов.
4. Вернитесь во Flasher и выберите Read again. ADB и fastboot — разные интерфейсы, поэтому для нового появившегося интерфейса fastboot может понадобиться ещё одна установка драйвера. Если задание установки завершилось ошибкой, следуйте указаниям приложения: снова прочитайте устройство и выберите Repair; не прошивайте разделы вручную.

Если при подключении модема в диспетчере устройств не появляется ни одного USB-устройства, сначала проверьте питание, USB-соединение и прямое подключение к порту USB. Это не то же самое, что устройство в списке, для которого не хватает драйвера обмена данными. Не отключайте модем для поиска неисправностей, пока идёт прошивка.

::: info Проверено на оборудовании с Windows
Официальная сборка 0.2.0-beta.2 для Windows amd64 выполнила установку на UFI003 со штатного Android 4.4 до OpenStick Debian 11 (ядро `5.15.0-handsomekernel+`), поддержки устройства 0.2.1 и ретранслятора 0.1.5~beta.2. Все 49 шагов установки и проверки слоёв прошли успешно, включая автоматическое резервное копирование и восстановление четырёх разделов калибровки модема. Отдельное обновление ретранслятора, распознавание устройства fastboot и передача данных в ОЗУ также прошли успешно. Драйверы по-прежнему должны соответствовать фактическим USB-интерфейсам и ИД оборудования устройства.

Подписанный список пакетов рекомендует исправленный [пакет поддержки устройства](https://github.com/OpenXPlay/OpenXPlay-Hardware/releases) версии 0.2.1 или новее. Не отключайте проверку подписи и используйте файлы, соответствующие списку.
:::

::: details Скачайте и откройте Flasher {#flasher-download}
Выберите **0.2.0-beta.2 или новее**, включая предварительные выпуски, в [Releases](https://github.com/OpenXPlay/OpenXPlay-Flasher/releases). Скачайте сборку для своей системы и сверьте её SHA-256 с файлом `SHA256SUMS` этого выпуска. Сборки не подписаны сертификатом Apple или Microsoft, поэтому при первом открытии система запросит подтверждение.

- **macOS 12 или новее** (Apple silicon и Intel, `OpenXPlay-Flasher-<version>-macos-universal.dmg`): перетащите приложение в папку «Программы» и один раз откройте его. В macOS 15 или новее, когда появится сообщение, что приложение не было открыто, выберите «Готово», затем перейдите в «Системные настройки» → «Конфиденциальность и безопасность» и выберите «Всё равно открыть» рядом с сообщением об OpenXPlay Flasher. В macOS с 12 по 14 щёлкните приложение, удерживая Control, выберите «Открыть», затем снова «Открыть».
- **Windows 10 или 11** (`openxplay-flasher-windows-amd64.exe` или `-arm64.exe` на ПК с Arm): когда появится окно «Система Windows защитила ваш компьютер», выберите «Подробнее», затем «Выполнить в любом случае». Если приложение сообщит, что отсутствует среда выполнения Microsoft Edge WebView2, установите её и снова откройте приложение.
:::

После запуска Flasher проведёт вас через следующие шаги:

1. **Подключение**: подключите UFI003 к компьютеру. Flasher покажет серийный номер модема и версию каждого слоя. Совершенно новый модем ещё работает на оригинальной прошивке и появляется в списке *other Android devices … connected and ignored* со своей моделью (обычно `msm8916_32_512`) и серийным номером; проверьте их, затем выберите *This is a UFI003 with its original firmware*, и Flasher прочитает модель для подтверждения.
2. **Выбор**: первым идёт рекомендуемое действие, например *Install OpenXPlay from the original firmware* для нового модема или *Install / update relay* для уже настроенного. Остальные действия, стирающие модем (переустановка базовой системы, полная переустановка, восстановление), находятся в разделе *Reflash (erases the device)*.
3. **Подготовка**: Flasher перечисляет все нужные файлы с их SHA-256 и ссылками для загрузки, но сам ничего не скачивает. Скачайте файлы по ссылкам или из другого надёжного источника, затем выберите *Choose file…* или *Choose several files…*. Flasher распознаёт файлы по SHA-256, поэтому их имена не важны. Не перемещайте и не удаляйте их до завершения установки.
4. **Резервное копирование** (только при прошивке базовой системы): Flasher считывает с модема разделы `modemst1`, `modemst2`, `fsc` и `fsg` и сохраняет их в `OpenXPlay Backups` в папке «Документы». В них хранятся данные калибровки модема, уникальные для этого устройства, поэтому храните эту папку всегда. Оригинальный загрузчик не может прочитать эти разделы, поэтому при установке с оригинальной прошивки Flasher сначала заменяет загрузчик и стирает раздел boot, затем делает резервную копию и устанавливает систему только после того, как резервное копирование прошло успешно. Действия, стирающие модем, также просят ввести его серийный номер.
5. **Прошивка**: сначала Flasher показывает, что сделает эта установка и сколько она примерно займёт (от 6 до 7 минут с оригинальной прошивки). Модем несколько раз перезагрузится; не отключайте его. Если соединение по пути прервётся, подключите модем снова и выберите *Repair*: Flasher продолжит с места остановки и восстановит эти четыре раздела из сделанной ранее резервной копии.
6. **Готово**: Flasher проверяет версию каждого слоя и в разделе *Next steps* предлагает кнопки, чтобы [добавить идентификатор CarPlay](#step-identity) и открыть страницу администрирования ретранслятора по USB.

::: details Список пакетов и подпись {#flasher-catalog}
Flasher читает с этого сайта подписанный список пакетов с версией, ссылками для загрузки и SHA-256 каждого слоя. Подпись подтверждает, что список получен от OpenXPlay, и каждый выбранный вами файл должен соответствовать указанному в нём SHA-256. Если вам нужен собственный список пакетов, можно выключить *Verify the package list signature* в настройках; файлы всё равно проверяются по SHA-256 из списка, а файлы базовой системы по-прежнему должны в точности совпадать с OpenStick v1.
:::

## После установки {#after-install}

Каким бы способом вы ни выполнили установку, дальнейшие шаги одинаковы.

## Добавьте идентификатор CarPlay {#step-identity .step}

Установочные пакеты никогда не содержат идентификатора аксессуара Apple (MFi); вы предоставляете собственный. Подключив модем к компьютеру по USB, откройте Flasher и выберите *Choose identity files or ZIP…* в разделе *Next steps*. Выберите закрытый ключ и сертификат (DER или PEM, в любом порядке и с любыми именами файлов) или ZIP-архив, содержащий `identity.pk8` и `certificate.p7b`. Flasher скопирует их на модем по USB и перезапустит ретранслятор.

## Откройте страницу администрирования {#step-admin .step}

Подключив модем к компьютеру по USB, выберите во Flasher *Open the relay admin page over USB* в разделе *Next steps*. В автомобиле подключите телефон к точке доступа ретранслятора `OpenXPlay-Linux-XXXX` (пароль — `openxplay`, если вы не задали свой), затем откройте `https://openxplay-car.local:6975` или `https://10.77.0.1:6975`. Браузер покажет предупреждение о сертификате; перейдите на страницу. Начальный пароль — `openxplay`, он также указан на странице входа; после входа страница попросит задать собственный.

Главный экран показывает, насколько продвинулось подключение по цепочке iPhone → этот ретранслятор → автомобиль, и под ней — единственное действие, которое нужно сейчас. Нажмите любой шаг, чтобы увидеть подробности и способ исправления. Шестерёнка вверху главного экрана открывает настройки.

При точке доступа автомобиля (см. следующий шаг) подключите телефон к точке доступа автомобиля и откройте `https://openxplay-car.local:6975` или IP-адрес, который точка доступа автомобиля выдала ретранслятору: `https://<IP ретранслятора>:6975/`. iPhone, Mac и компьютеры с Windows открывают адреса `.local`; многие телефоны на Android — нет, поэтому на них используйте IP-адрес. Адрес, введённый без `https://`, тоже открывается. В UFI003 только один радиомодуль Wi-Fi, поэтому он не может держать точку доступа администрирования.

## Выберите сеть {#step-network .step}

На странице администрирования в **Settings → iPhone connection → Wireless network** выберите, как iPhone и головное устройство связываются с ретранслятором:

- **This relay’s hotspot** (по умолчанию): открывает собственную точку доступа ретранслятора; iPhone подключается к ней автоматически, головное устройство тоже подключается к ней.
- **Use the car’s hotspot**: ретранслятор, iPhone и головное устройство подключаются к точке доступа автомобиля или к другой существующей сети 2,4 ГГц.

UFI003 показывает CarPlay только в браузере головного устройства; для Carlink нужен второй адаптер Wi-Fi, см. [Приложение Carlink](/ru/carlink).

## Выполните сопряжение с iPhone {#step-pair .step}

Когда главный экран предложит выполнить сопряжение с iPhone, нажмите *Pair*; сопряжение остаётся открытым 10 минут. На iPhone откройте «Настройки» → Bluetooth и выберите `OpenXPlay Linux`. Для нового iPhone удалите старое сопряжённое устройство на главном экране или в Settings → iPhone connection.

## Откройте CarPlay в браузере головного устройства {#step-open .step}

Подключите головное устройство к сети ретранслятора и откройте `https://10.77.0.1:8443/` (при собственной точке доступа ретранслятора) или `https://openxplay-car.local:8443/`. В первый раз примите предупреждение о сертификате; почему оно появляется, объясняет раздел [Решение проблем](/ru/troubleshooting#certificate-warning).

Если на странице администрирования в Settings → Head-unit access включено *Require pairing code*, введите 8-значный код, который показывает ретранслятор.

## Установка из командной строки без Flasher {#manual}

Если вы хотите пользоваться только командной строкой, без Flasher, можно прошить модем вручную, а затем установить пакет устройства и пакет ретранслятора. При этом пропускаются резервное копирование и проверки Flasher, а прошивка заменяет оригинальную систему модема, поэтому убедитесь, что понимаете каждый шаг.

::: details Показать шаги для командной строки

### Прошейте базовый образ {#step-image}

Прошейте на UFI003 образ OpenStick Debian 11 (ядро `5.15.0-handsomekernel+`, aarch64). Ссылки для загрузки, контрольные суммы и предостережения, с которыми нужно ознакомиться перед прошивкой, приведены на странице [Прошивка базового образа UFI003](/ru/ufi003-flash).

### Установите пакет устройства {#step-device}

В [Releases](https://github.com/OpenXPlay/OpenXPlay-Hardware/releases) OpenXPlay-Hardware выберите самый новый выпуск `ufi003-device-v` (требуется 0.2.1 или новее), скачайте `openxplay-ufi003-device-<version>.tar.gz` и `SHA256SUMS` и проверьте их. Скопируйте архив на модем и откройте его оболочку (root):

```sh
V=0.2.1
adb push openxplay-ufi003-device-$V.tar.gz /root/
adb shell
```

Задайте в `V` скачанную версию. На модеме задайте `V` так же, затем распакуйте архив и запустите установщик. `--dry-run` проверяет всё, ничего не меняя; после установки перезагрузите модем:

```sh
V=0.2.1
cd /root
tar -xzf openxplay-ufi003-device-$V.tar.gz
sh openxplay-ufi003-device-$V/install-device.sh --dry-run
sh openxplay-ufi003-device-$V/install-device.sh
reboot
```

После перезагрузки снова откройте `adb shell` и проверьте устройство с `--verify`:

```sh
V=0.2.1
sh /root/openxplay-ufi003-device-$V/install-device.sh --verify
```

Пакет устройства содержит нужные ему пакеты Debian, поэтому устанавливается без подключения к интернету. Он добавляет модуль Bluetooth RFCOMM, необходимый для беспроводного CarPlay, исправленный драйвер Bluetooth, защиту Bluetooth и профиль хоста, а также включает синхронизацию времени.

### Установите ретранслятор {#step-install}

В [Releases](https://github.com/OpenXPlay/OpenXPlay-Relay/releases) выберите последний выпуск `linux-v`, скачайте `.deb` и `SHA256SUMS` и проверьте их, затем выполните на компьютере:

```sh
V=0.1.6
adb push openxplay-relay_${V}_arm64.deb /root/
adb shell dpkg -i /root/openxplay-relay_${V}_arm64.deb
```

Задайте в `V` последнюю версию. Пакет устройства уже установил зависимости, поэтому подключение к интернету не нужно. Что настраивает пакет, описано в разделе [Установите ретранслятор](/ru/linux-devices#install).

Чтобы собрать их самостоятельно: пакет устройства — с помощью `UFI003/package/build-bundle.sh` в [OpenXPlay-Hardware](https://github.com/OpenXPlay/OpenXPlay-Hardware), пакет ретранслятора — с помощью `rust/packaging/build-deb.sh` в [OpenXPlay-Relay](https://github.com/OpenXPlay/OpenXPlay-Relay).

Затем продолжайте с раздела [Откройте страницу администрирования](#step-admin). Без Flasher добавьте идентификатор CarPlay на странице администрирования в **Settings → Identity and certificates** или [разместите файлы идентификатора вручную](/ru/linux-devices#identity).

:::

## Что дальше {#next-steps}

- В автомобилях вроде XPeng G6 см. рекомендуемую настройку в разделе [Головные устройства](/ru/head-units), например установку частоты кадров 30 на 2,4 ГГц: измените её на странице администрирования в **Settings → CarPlay picture → Frame rate**, и страница головного устройства последует за ней.
- Чтобы сообщить о проблеме, сохраните журналы в файл в **Settings → Logs** или отправьте их и сообщите нам ID журнала.
- [Доверенный HTTPS](/ru/trusted-https): избавьтесь от предупреждения о сертификате с помощью бесплатного доменного имени.
- Что-то не работает? См. [Решение проблем](/ru/troubleshooting).
