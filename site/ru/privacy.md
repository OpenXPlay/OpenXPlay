# Политика конфиденциальности

Эта политика распространяется на решение с ретранслятором, опубликованное OpenXPlay.org: приложение OpenXPlay Relay для Android, Linux-ретранслятор и этот сайт. Последнее обновление: 13 ноября 2026 г.

::: tip Прямое подключение iPhone
У приложения OpenXPlay для iPhone, которое подключается к головному устройству без ретранслятора, есть собственная [политика конфиденциальности на openxplay.com](https://openxplay.com/ru/privacy).
:::

## Кратко {#summary}

- В OpenXPlay нет учётной записи, рекламы, аналитики и отслеживания.
- Видео, звук и касания CarPlay передаются только между вашим iPhone, ретранслятором и головным устройством. Они никогда не проходят через наши серверы.
- Журналы приложения для Android остаются на телефоне-ретрансляторе, если вы сами не решите их отправить. Отправленные журналы удаляются в течение 30 дней.

## Что остаётся на ретрансляторе {#on-device}

- **CarPlay.** Ретранслятор сам отдаёт страницу приёмника и свою страницу администрирования. Видео, звук и касания передаются между iPhone, ретранслятором и головным устройством по Bluetooth, Wi-Fi или USB.
- **Настройки.** Ваши настройки, сопряжение с iPhone и головные устройства, которым доверяет ретранслятор, хранятся на ретрансляторе.
- **Сведения об автомобиле.** Сведения об автомобиле, которые сообщают головные устройства с Carlink, собираются, только если вы это включите, и остаются на ретрансляторе.
- **Плагины.** Плагины по умолчанию выключены и работают офлайн в браузере головного устройства.
- **Журналы.** Приложение для Android хранит на телефоне собственные журналы примерно за последние 24 часа. Перед сохранением пароли, ключи, номера телефонов, имена, сообщения и точное местоположение заменяются. Технические сведения, такие как модель телефона, версия системы, адреса Bluetooth и Wi-Fi, IP-адреса и имена сетей Wi-Fi, сохраняются, потому что они нужны для поиска проблем с подключением.

## Когда данные покидают ретранслятор {#sent}

- **Отправка журналов (приложение для Android).** Отправка происходит только после того, как вы примете уведомление в Settings › Logs. Журнал отправляется на `logs.openxplay.org`, который обслуживает OpenXPlay.org, и используется только для диагностики проблем. Отправленные данные проходят через Cloudflare, который пересылает их без сохранения, на сервер, который может находиться в центре обработки данных AWS в США. Отправки из одного приложения связаны случайным идентификатором, который не выводится из вашего iPhone, автомобиля или оборудования телефона. Отправленные журналы нельзя скачать публично, и они безвозвратно удаляются не позднее чем через 30 дней; чтобы удалить журнал раньше, отправьте его идентификатор на [support@openxplay.org](mailto:support@openxplay.org). При желании вместо этого сохраните файл и отправьте его лично.
- **Доверенный HTTPS.** Если вы настроите доверенное имя для браузеров головных устройств, ретранслятор отправляет свой адрес выбранному вами поставщику динамического DNS (DuckDNS или dynv6), используя ваш токен, и запрашивает сертификат у Let's Encrypt. Имя и частный адрес, на который оно указывает, становятся публичными; см. [Доверенный HTTPS › Конфиденциальность](/ru/trusted-https#privacy). Действуют собственные политики конфиденциальности этих служб.
- **Проверка обновлений.** Ретранслятор запрашивает у GitHub список выпусков OpenXPlay Relay. GitHub видит публичный адрес интернет-подключения ретранслятора.

Мы не продаём данные и никому их не передаём.

## Безопасность {#security}

Страница администрирования использует HTTPS и требует пароль администратора. Страница входа показывает пароль для первого входа; измените его после входа. Пока используется пароль по умолчанию, страница администрирования напоминает об этом.

## Этот сайт {#website}

На openxplay.org нет аналитики, а его [страница проверки](/ru/check) работает только в вашем браузере.

## Дети {#children}

OpenXPlay не предназначен для детей и сознательно не собирает их данные.

## Изменения и контакты {#contact}

Если эта политика изменится, новая версия будет опубликована на этой странице с новой датой. Вопросы и запросы о ваших данных: [support@openxplay.org](mailto:support@openxplay.org).
