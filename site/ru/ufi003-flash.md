# Прошивка базового образа UFI003

На UFI003 работает OpenStick [выпуска v1](https://github.com/OpenStick/OpenStick/releases/tag/v1) (опубликован 2022-02-08) — система Debian 11. Эта страница — первый шаг [установки из командной строки без Flasher](/ru/ufi003-relay#manual); после прошивки модема вернитесь на страницу [UFI003 в роли ретранслятора](/ru/ufi003-relay#step-device), чтобы установить пакет устройства и ретранслятор. Рекомендуемые способы — [доверить установку ИИ-ассистенту](/ru/ufi003-relay#ai) или [установить самостоятельно с помощью Flasher](/ru/ufi003-relay#flasher): OpenXPlay Flasher выполняет шаги с этой страницы и автоматически создаёт резервную копию четырёх разделов модема. Исходный загрузчик не может прочитать эти разделы, поэтому при первой установке со штатной системы Flasher сначала заменяет загрузчик и стирает раздел boot, затем создаёт резервную копию и устанавливает систему только после того, как резервное копирование прошло успешно.

::: danger Перед прошивкой
- Пакет прошивки заменяет таблицу разделов и загрузчик. Штатная система Android после этого работать не будет, а способа вернуться OpenStick не предусматривает.
- Перед первой прошивкой создайте резервную копию всего устройства, и как минимум разделов `modemst1`, `modemst2`, `fsc` и `fsg`: в них хранятся уникальные для этого устройства данные калибровки модема, которые невозможно восстановить из другого источника.
- Прошивка стирает с устройства всё, включая добавленный вами идентификатор CarPlay, сопряжения с iPhone и настройки Wi-Fi.
:::

## Скачайте и проверьте файлы {#downloads}

OpenStick запрещает коммерческое использование, и OpenXPlay не распространяет эти файлы: скачайте их со страницы выпуска OpenStick и проверьте их SHA-256 (`shasum -a 256 FILE` в macOS, `sha256sum FILE` в Linux):

| Файл | Назначение |
| --- | --- |
| [`debian.zip`](https://github.com/OpenStick/OpenStick/releases/download/v1/debian.zip) (около 377 МБ) | Корневая файловая система Debian 11 `rootfs.img` и копия `boot.img` |
| [`boot-ufi001c.img`](https://github.com/OpenStick/OpenStick/releases/download/v1/boot-ufi001c.img) | Загрузочный раздел ядра для UFI003; это не тот же файл, что универсальный `boot.img` в `debian.zip` |
| [`base-generic.zip`](https://github.com/OpenStick/OpenStick/releases/download/v1/base-generic.zip) | Загрузчик и другие низкоуровневые разделы со скриптом прошивки; нужен только для первой прошивки со штатной системы |

::: details Контрольные суммы SHA-256 {#checksums}
| Файл | SHA-256 |
| --- | --- |
| `debian.zip` | `8be6f100e8fc3f612e0b03c199d01f51d38b953a19343ad0f4cf7a2f7a57f603` |
| `boot-ufi001c.img` | `a2b527e98a5cee0a4c3cad5099af7ce0648246f19d20d13ef2c168e400c81b33` |

Остальные файлы `boot-*.img` и `firmware-*.zip` на странице выпуска предназначены для других моделей; UFI003 они не нужны.

## Первая прошивка со штатной системы {#first-flash}

Для первой прошивки нужны загрузчик и скрипт прошивки `flash.sh` из `base-generic.zip`. **Не запускайте скрипт как есть** по причинам, описанным ниже: выполняйте его команды построчно и продолжайте только после того, как все четыре раздела прочитаны с вашего устройства и файлы действительно заменены.

::: details Почему нельзя просто запустить flash.sh? {#flash-script}
`flash.sh` сначала стирает раздел boot и устанавливает новый загрузчик, только потом сохраняет разделы `modemst1`, `modemst2`, `fsc` и `fsg` в одноимённые файлы `.bin` и в конце записывает их обратно. В архиве уже есть четыре таких файла `.bin`, три из которых содержат реальные данные, но не данные вашего устройства. Скрипт не останавливается при ошибке шага, поэтому если резервное копирование не удастся, на ваше устройство будут записаны файлы из архива.
:::

## Повторная прошивка модема с OpenStick {#reflash}

Чтобы перепрошить UFI003, на котором уже работает OpenStick, достаточно записать корневую файловую систему и раздел boot. Распакуйте `debian.zip`, положите `boot-ufi001c.img` в его каталог `debian` и выполните в нём эти команды. Не запускайте `flash.sh` из этого каталога как есть: он записывает универсальный `boot.img`.

```sh
adb reboot bootloader
fastboot -S 200M flash rootfs rootfs.img
fastboot flash boot boot-ufi001c.img
fastboot reboot
```

::: warning Записывайте rootfs.img с -S 200M
Записывайте `rootfs.img` с параметром fastboot `-S 200M` (так делает `flash.sh` из `debian.zip`). С блоками по умолчанию размером около 256 МБ запись на UFI003 обрывается на середине.
:::
