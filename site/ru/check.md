# Проверка головного устройства

Откройте эту страницу в браузере головного устройства, чтобы проверить, есть ли в нём функции, которые использует веб-приёмник OpenXPlay: декодирование видео H.264 и H.265 через WebCodecs, WebSocket, звук, микрофон, мультитач и размер экрана. Затем страница выдаст вывод и отчёт, который можно скопировать. Всё выполняется в браузере: ничего не отправляется и не сохраняется.

На головном устройстве введите <code>{{ $frontmatter.checkAddress }}</code> в адресную строку браузера. Для этого головному устройству нужен доступ в интернет, например через точку доступа вашего телефона. Без интернета ретранслятор сам отдаёт страницу проверки декодера по пути `/probe/` на адресе приёмника, например `https://10.77.0.1:8443/probe/`.

## Что означают результаты {#meaning}

| Вывод | Значение |
| --- | --- |
| Проверка пройдена, с H.265 | Браузер сообщает о функциях видео, звука и микрофона, которые использует веб-приёмник, и указывает, что может аппаратно декодировать H.265 (HEVC), поэтому ретранслятор может использовать H.265. |
| Проверка пройдена, только H.264 | Браузер сообщает об этих функциях, но не указывает на аппаратное декодирование H.265. Для любого экрана, который не может аппаратно декодировать H.265, ретранслятор использует H.264. |
| Изображение будет, но части функций нет | Всё необходимое для изображения есть, но нет звука (AudioWorklet) или API микрофона: CarPlay показывается, но звук, Siri или звонки через браузер могут не работать. |
| Не поддерживается: нужен браузер с WebCodecs | Нет обязательной функции, чаще всего декодирования видео через WebCodecs. Если на головном устройстве есть другой браузер, попробуйте его, или используйте [приложение Carlink](/ru/carlink). |

Проверка только спрашивает браузер, что он поддерживает: она не воспроизводит видео, не подключается к ретранслятору, не записывает звук и не передаёт касания. Поэтому успешный результат не гарантирует плавного воспроизведения, которое зависит также от оборудования головного устройства и подключения Wi-Fi. Результаты из автомобилей собраны в разделе [Головные устройства](/ru/head-units).

## Что проверяется {#what-is-checked}

::: details Что проверяет каждый пункт и зачем {#checked-items}
| Пункт | Зачем он нужен |
| --- | --- |
| Защищённая страница (HTTPS) | Браузеры включают WebCodecs только на защищённых страницах, поэтому ретранслятор отдаёт приёмник по HTTPS. |
| WebCodecs VideoDecoder | С его помощью веб-приёмник декодирует видео CarPlay. Без него браузер не может показывать CarPlay. |
| H.264 (AVC) | Базовый формат видео. Ретранслятор переходит на него всякий раз, когда H.265 невозможен. |
| H.265 (HEVC) | Используется, только если каждый экран, показывающий CarPlay, декодирует его аппаратно. |
| Аппаратное декодирование | Программное декодирование требует больше вычислительных ресурсов, и видео может подтормаживать. |
| Web Workers и OffscreenCanvas | Приёмник декодирует и отрисовывает видео вне основного потока страницы. |
| WebSocket | Передаёт видео, звук и касания между ретранслятором и браузером. |
| AudioContext и AudioWorklet | Воспроизводят звук CarPlay. Декодирование AAC через WebCodecs AudioDecoder необязательно. |
| Микрофон (getUserMedia) | Позволяет Siri и звонкам использовать микрофон головного устройства после того, как вы разрешите это в браузере. |
| Точки касания | Касания передаются обратно на iPhone. Две и более точки позволяют использовать жесты несколькими пальцами. |
| Размер экрана и плотность пикселей | Приёмник сообщает их ретранслятору вместе с форматами видео, которые может декодировать. |
:::
