# Tesla <Badge type="warning" text="Экспериментально" />

Tesla показывает CarPlay в собственном браузере, как и другие головные устройства, с одним отличием: браузер Tesla не открывает адреса локальной сети, например `192.168.43.20`. Поэтому ретранслятор добавляет адрес, который Tesla может открыть, через локальный VPN на телефоне-ретрансляторе; ничего не покидает телефон.

::: tip Версия
Эта адаптация есть в приложении для Android 0.2.0 и в Linux-ретрансляторе 0.1.6. Расскажите, как она работает у вас, в [сообществе](/ru/community).
:::

## Что понадобится {#requirements}

- Приложение для Android 0.2.0 или новее ([скачать последнюю версию](https://github.com/OpenXPlay/OpenXPlay-Relay/releases/latest/download/openxplay-relay.apk)); начиная с 0.2.2 у него есть отдельная страница настроек.
- Tesla с MCU2 или новее.
- Беспроводной CarPlay: подключение по USB уже занимает единственный VPN в Android.
- Вывод *Car browser*.
- Tesla подключена к точке доступа телефона-ретранслятора (по возможности 5 ГГц) или к его сети Wi-Fi Direct. *Use the car’s hotspot* не работает: точка доступа автомобиля не передаёт адрес телефону.
- В настройках Wi-Fi Tesla включён параметр *Remain Connected in Drive*.

## Настройка {#setup}

1. Настройте ретранслятор, как описано в разделе [Телефон Android в роли ретранслятора](/ru/android-relay), и выберите Tesla и свою модель в разделе *Your car*.
2. В приложении откройте Settings → *Tesla browser* и выберите один из способов ниже. Для способов с доверенным именем сначала нужен [доверенный HTTPS](/ru/trusted-https). При первом включении Android запросит согласие на VPN.
3. Запустите CarPlay. На главном экране адрес для Tesla указан первым; откройте его в браузере Tesla.

| Способ | Адрес на телефоне | Что нужно знать |
| --- | --- | --- |
| Доверенное имя + адрес из общего диапазона (TeslaMirror, рекомендуется) | `100.88.0.1` | Нужен доверенный HTTPS; Tesla открывает ваше доверенное имя без предупреждения о сертификате. |
| Доверенное имя, локальный адрес канала (link-local) | `169.254.88.1` | Нужен доверенный HTTPS. Чтобы найти имя, Tesla нужен интернет через точку доступа телефона. |
| Прямой локальный адрес канала (link-local) | `169.254.88.1` | Учётная запись не нужна: откройте `https://169.254.88.1:8443` и продолжите, несмотря на предупреждение о сертификате. Работает, только если браузер Tesla позволяет продолжить. |
| Адрес из публичного диапазона (как в TeslaAndroid) | `3.3.3.1` | Откройте адрес и продолжите, несмотря на предупреждение о сертификате. |
| Выключено | | По умолчанию. |

Адрес на телефоне можно изменить. При переключении между способами CarPlay продолжает работать.

::: details Android 13 и новее
Android 13 и новее может сбрасывать подключения от точки доступа к адресу вне `169.254`; это наблюдалось на Android 15. Если Tesla не может открыть страницу, используйте способ с адресом `169.254`. Приложение предупреждает, когда это относится к вам.
:::

## Linux-ретранслятор {#linux}

В Linux-ретрансляторе те же способы есть начиная с 0.1.6: на его странице администрирования включите браузер Tesla, выберите вывод *Car browser* и собственную точку доступа ретранслятора. Ретранслятор добавляет адрес в свою точку доступа и удаляет его, когда вы останавливаете ретранслятор; для способов с доверенным именем здесь тоже нужен доверенный HTTPS.
