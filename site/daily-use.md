# 日常使用与设置

第一次设置完成后，每次上车只需要打开中继、在车机浏览器中打开同一个地址。

## 每次上车 {#daily}

使用安卓手机作中继时：

1. 上车后打开 OpenXPlay Relay，点“用上次的配置开启”。开启自动连接时，5 秒后会自动用上次的配置开启。
2. 确认车机和中继手机已连上同一个网络。
3. 在车机浏览器中打开书签里的地址，轻触一下屏幕。

使用 UFI003 时，中继作为系统服务运行，通电后自动启动；车机连上中继的网络后，打开书签里的地址即可。

## 车机网页的设置 {#web-settings}

使用安卓中继时，点车机网页角落的齿轮按钮可以打开设置。更改分辨率或屏幕宽度后，CarPlay 会在几秒后重新连接。

| 设置 | 作用 |
| --- | --- |
| 分辨率 | 自动、原画、1080p、720p、整屏。“原画”按车机屏幕的原始像素显示，画面最清晰，但需要更多 Wi-Fi 带宽；车机浏览器解码不了时会自动降低。 |
| CarPlay 屏幕宽度 | 125、200、250、300 mm。这是告诉 iPhone 的屏幕尺寸，数值越大，一屏显示的图标越多，默认 200 mm。 |
| 全屏 | 让网页占满车机屏幕。 |
| 轻触恢复全屏 | 倒车影像等界面会让浏览器退出全屏。回到网页后，页面会提示“轻触屏幕恢复全屏”，轻触一下即可。关闭后，页面保持窗口，CarPlay 画面会适配窗口。 |

::: details 为什么恢复全屏要轻触一下？
浏览器规定进入全屏必须由一次点击触发，所以网页不能自己恢复全屏。这一下轻触不会点到 CarPlay。
:::

## 选择车型（可选） {#car-model}

在应用的“设置 → 车型与屏幕”中选择车的品牌和型号，目前内置了小鹏 G6 2023 款的屏幕数据；列表里没有你的车时，选“其他”并输入品牌和型号。

同一处的“CarPlay 显示区域”默认开启：车机浏览器窗口变化时（进入或退出全屏、分屏），CarPlay 画面随之调整，不用重新连接。这里还会显示中继检测到的车机屏幕数据，下次启动 CarPlay 时会用这些数据优化显示。

::: tip 帮更多车型用上
如果你的车型不在列表里，欢迎点“点击该按钮复制我的车机屏幕数据”，到[交流群](/community)发给开发者，之后的版本就会自带你的车型数据。
:::

## 更新 {#updates}

新版本发布在 [Releases](https://github.com/OpenXPlay/OpenXPlay-Relay/releases)，每个版本的变化见[更新日志](/changelog)。安卓应用更新后，车机网页会自动刷新一次，换成新版本。
